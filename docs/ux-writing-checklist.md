# UX ライティング・文章品質チェックリスト

UI 文言・エラーメッセージ・README・設計ドキュメントを公開／マージする前に確認する 8 項目です。  
**4 つの品質軸**：文章の自然さ ／ 意味の正確さ ／ 概念の一貫性 ／ 情報量の適切さ

- [ ] **1. 一読理解**：初見の読者が 1 回読んで引っかかりなく意味を理解できるか
- [ ] **2. 不要な専門用語の排除**：読者に不要な専門語・社内語・未翻訳の英単語が混じっていないか（必要な専門語には初出で短い補足があるか）
- [ ] **3. 抽象の具体化**：「処理を実行」「適切に提供」などの抽象表現を、具体的な行動・結果に言い換えられないか
- [ ] **4. 用語の一貫性**：同じ概念に対して、画面・セクション・ドキュメント全体で同じ用語を使っているか
- [ ] **5. 次行動の明確化**：ボタン文言やエラー文を見ただけで「押すと何が起きるか／次に何をすればよいか」が分かるか
- [ ] **6. 実装・事実との一致**：現在の機能・科学的スコープ・制約と説明が厳密に一致しているか（過剰主張がないか）
- [ ] **7. 冗長文の削ぎ落とし**：削除しても意味が変わらない重複説明や回りくどい修飾語が残っていないか
- [ ] **8. 利用者視点**：システム内部の都合ではなく、利用者の目的達成の視点で書かれているか

背景と FoldLens での具体的な改善例は [ux-writing-in-scientific-ai.md](ux-writing-in-scientific-ai.md) を参照してください。
